# デモで初期設定を試す順序

画面のメールはすべて架空です。実際のGmail設定や配信停止の結果を正確に再現するものではありません。最初は各操作の違いと見落としの起き方を確かめ、実アカウントでは少数から試してください。

## 1. 受信トレイの表示を比較する

左側で「カテゴリ別」に切り替え、「プロモーション」を開きます。サンプル旅行の「予約の最終確認」は必要なメールですが、ここに入っています。「優先トレイ」に戻しても、重要マークがないため上位に出ません。つまり、表示方法を変えるだけでは重要メールを全部拾えません。

実アカウントでは、最初に「メイン」「更新」「プロモーション」と迷惑メールを少量確認し、必要なメールがどこに入っているかを記録します。

## 2. 必要な印を使い分ける

サンプル旅行を選び「☆ スターを付ける」と「保護する」を試します。スターは対応を追う印、保護はデモ内の「保存したい」印です。Gmailでは「保護」という特別な機能はなく、専用ラベルを自分で作る想定です。重要マークはGmailの優先順位付けに使われますが、誤判定もあり得ます。

「既読にする」も試してください。既読にしても対応済みにはなりません。未処理の要件を見失わないため、スターなどの別の印を残すかを考えます。

## 3. 配信停止の粒度を比べる

「最初から試す」を押し、サンプル商店の「この配信だけ停止」を選んでから「次の週を受信」します。販促メールは減り、注文確認は届きます。

もう一度リセットし、今度は「送信者を一括停止」を選んで次の週を受信します。注文確認が見落とし候補になります。Gmailの「購読を管理」から送信者を解除すると、その送信者に関連する有効な配信リストをまとめて解除し、その後の新着が迷惑メールへ移ることがあります。一方、メール単位のワンクリック解除は対象の配信リスト単位です。デモの注文確認への影響は架空の例なので、実際には配信内容と後日届いたメールを確かめます。[Gmailの購読管理](https://support.google.com/mail/answer/15621070?co=GENIE.Platform%3DDesktop)・[ワンクリック解除の範囲](https://support.google.com/mail/answer/14229414?hl=en)

## 4. 後で読む配信を分ける

リセットして「読み物は『後で読む』へ」にチェックを付け、次の週を受信します。週刊サンプルの新着は受信トレイから外れます。実アカウントでは、これを使う前に「後で読む」ラベルを定期的に見る習慣があるか確かめます。

## 5. 実アカウントへの移行判定

次の三つに答えられるまで、大量削除・一括既読・広い自動フィルタは保留します。

1. 今週の重要メールは、表示方法を変えても見つけられたか。
2. 停止候補の差出人が、領収書・予約・認証などにも使われていないか。
3. 「後で読む」へ移した配信を、実際に見返せるか。

デモが網羅できない例と、実アカウントでの確認方法は[coverage.md](coverage.md)にまとめています。
