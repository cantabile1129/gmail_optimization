# デモの範囲と実アカウントでの検証計画

## デモで試せること

- 優先トレイ、カテゴリ別、未読優先でメールの見え方が変わること。
- スター、重要マーク、保護ラベル、未読が別の役割を持つこと。
- アーカイブは受信トレイから外す操作であり、削除と違うこと。
- 配信リスト単位の停止と送信者一括停止では、同じ差出人の注文確認への影響が違うこと。
- 読み物を「後で読む」に振り分けると、新着が受信トレイに積み上がらないこと。
- 重要な予約確認がプロモーションに誤分類される例。

## デモだけでは検証できないこと

| 論点 | 実アカウントで確かめる方法 |
|---|---|
| Gmailの重要マーク・カテゴリの誤分類 | 最新のメールを少量サンプリングし、重要なのに下位表示された件数を記録する。迷惑メールも別途確認する。 |
| 差出人やドメインの混在 | 受信量上位の配信について、直近数通と同じ差出人の取引通知を確認する。 |
| `List-Id`がない購読メール | Gmailの「購読を管理」とメール上部の解除操作を実際に確認する。現版の候補判定は`List-Id`がなければ配信停止を勧めない。 |
| 件名に現れない重要性 | 人からのメール、期限、添付、本文の文脈を人が確認する。現在のツールは本文を取得しない。 |
| 以前の未読と長い会話 | 古い期間と会話をGmail検索で別途確認する。試作ツールは受信トレイの新しい指定件数だけを分析する。 |
| 解除後の実際の配信 | 数日後にそのリストの新着を確認し、必要な通知が迷惑メールに移っていないか見る。 |
| 個人の価値観 | 「保持した」「停止した」「後で読む」にした上位候補を振り返り、私的な設定ファイルの語と保護対象を調整する。 |

## 段階的な導入

1. **観察:** 既存のGmail設定を変更せず、受信量上位の配信と重要メールの見え方を確認する。
2. **手動試行:** 明らかな販促配信を数件だけ停止し、重要メールにスター・保護ラベルを試す。
3. **1つずつ設定:** 優先トレイや「後で読む」フィルタを1つずつ有効にし、各変更後に重要メールが見つけられるか確かめる。
4. **見直し:** 1〜2週間後、見落とし候補、迷惑メールへの誤移動、配信停止後の新着、処理時間を比較する。

削除・一括既読・広い差出人フィルタは、この確認が済むまで自動化しない。評価指標は未読件数だけでなく、重要メールを見つけられるかどうかを最優先にする。
